# Security Policy

## Supported Versions

Only the latest version of `extract-recommended-actions.ps1` on the default branch (`main`) is supported. Fixes are made there; older commits do not receive separate updates.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately by email to [trymhaak2@icloud.com](mailto:trymhaak2@icloud.com). Do not open a public GitHub issue for security problems.

The disclosure policy that applies to reports is published at https://trym.cloud/security/disclosure/.

A useful report includes:

- **Affected version**: the commit hash (or the date you downloaded the script) on which you observed the issue
- **Steps to reproduce**: what you ran, with which PowerShell and Microsoft Graph PowerShell SDK versions, and what happened
- **Impact**: what an attacker could achieve, and under which conditions

Please do not include real incident data, tenant identifiers or credentials in a report. Redact or replace them with placeholders.

## Good-Faith Research

Reports made in good faith are welcome. Please test only against Microsoft 365 tenants you own or are authorized to test, and avoid accessing, modifying or retaining other people's data.

This project does not run a bug bounty program.
