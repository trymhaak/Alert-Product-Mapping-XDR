# Release notes: v1.0.0 (DRAFT)

> **Draft.** This is a proposal for the first release. Version 1.0.0 has not been
> tagged or published.

## Summary

First release of the Microsoft Defender XDR Incident Analysis Tool: a read-only
PowerShell script for security operations that lists recent Microsoft Defender XDR
incidents and exports their alert titles, MITRE ATT&CK techniques and recommended
actions to CSV for review.

## What's included

- `extract-recommended-actions.ps1` (PowerShell 7.0+)
  - Interactive sign-in to Microsoft Graph with the single delegated scope
    `SecurityIncident.Read.All`. The script only reads data; it does not change
    incidents or alerts.
  - Retrieves incidents created in the last 30 days from the Microsoft Graph v1.0
    `security/incidents` endpoint, with alerts expanded and pagination handled.
  - Collects unique alert titles, MITRE ATT&CK technique IDs and recommended
    actions per incident.
  - Writes `IncidentCatalog_WithActions_YYYYMMDD_HHmmss.csv` (17 columns) to the
    current directory.
  - Prints a summary with breakdowns by severity, status and classification and
    coverage of recommended actions and MITRE ATT&CK mapping.
- Documentation: README, `SECURITY.md`, `CHANGELOG.md`, MIT license.

## Requirements

- PowerShell 7.0 or later
- Microsoft Graph PowerShell SDK (`Microsoft.Graph`, of which the script uses the
  `Microsoft.Graph.Authentication` module)
- An account that can be granted `SecurityIncident.Read.All`

## Known limitations

- The 30-day window and page size are fixed in the script; there are no
  command-line parameters.
- Only interactive delegated authentication is supported.
- The exported CSV contains incident data from your tenant, including the tenant ID.
  Store it accordingly and do not commit it (the repository's `.gitignore` excludes
  `IncidentCatalog_*.csv`).

## Upgrade notes

None. This is the first release.
